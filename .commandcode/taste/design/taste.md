# Design taste

- Prefers Android Material You over iOS for mobile app UI designs (strictly "not iOS"). Confidence: 0.9
- Avoids decorative gradients as backgrounds and decorative shadows; subtle shadow only on floating action elements. Confidence: 0.85
- Avoids numbered markers/section labels (01/02/03) unless they denote a literal step sequence. Confidence: 0.8
- Avoids pink as a primary color for women's health products (considers it cliché), preferring dusty mauve/plum tones instead. Confidence: 0.85
- Wants internal/research computation models kept strictly separate from the user-facing presentation model: technical values (CF scores, MB/MD, weights, formulas, rule/evidence IDs, inference-engine terms) must never be rendered in the end-user UI, which shows only plain-language conclusions, notable factors, and recommendations. Confidence: 0.85
- For sensitive data (e.g. GBV experiences), avoid logging sensitive answers and avoid showing more detail in the UI than needed, using non-judgmental/non-stigmatizing language. Confidence: 0.75
